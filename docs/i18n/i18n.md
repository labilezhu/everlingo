## 需求

现在的几个主要界面：

- [Web Chatbot](docs/impl-spec/web-chatbot.md)
- [Vault Editor](docs/impl-spec/vault-editor.md)
- [Chrome Extenstion](docs/impl-spec/chrome-extension-spec.md)
- [Chat Agent](docs/impl-spec/chat-agent-spec.md)

均需要作一些国际化的支持。暂时，我计划只实现两种语言的界面，即只有两种 `可用界面语言`：
- zh-CN
- en


请你就现在的技术 stack ，提出界面国际化的 high level 方案。如果需要分 phase 实施，请说明。

### 配置变更
- interface_language
    - everlingo.yaml 的 `interface_language(界面语言)` 现在是 “必选” 的，要修改为 “非必选”。
    - interface_language 如果非空，一定要在 `可用界面语言` 里取值。
    - interface_language 默认使用 python 的 `lang, encoding = locale.getlocale()` 获取操作系统语言，然后匹配 `可用界面语言`作为`interface_language`，如果匹配不到，那么默认选择 en 作为`interface_language`。
