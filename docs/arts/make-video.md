## 在 GitHub 网页编辑 README

打开你的 repository：

README.md → Edit

然后把 MP4 直接拖到 GitHub 的 Markdown 编辑框里。

GitHub 会上传视频，并生成一个类似：

https://github.com/user-attachments/assets/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

的 URL。

这个 URL 指向的是 GitHub 自己托管的视频。GitHub 官方文档明确说明，视频不会走 Camo，而是使用上传视频的 GitHub 匿名 URL。
