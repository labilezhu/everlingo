# EverLingo v0.1.0

经过数月我和 AI 的一起努力，记了么现在已经基本可用了。所以发布 0.1.0 版本。

这个版本的新特性包括：

笔记体验：
- 氛围记笔记， vibe noting。小记 Agent 可以感知笔记编辑器的上下文。你可以在笔记编辑器上选定一句话，让小记进一步解释，或让小记在笔记中补充你想要的内容。
- 支持笔记之间互相超链接
- 消息直接返回笔记超链接

用户体验：
- 移动端网页的支持，手机端体验提升。支持手机主屏加入网页应用(PWA)图标，快速启动。
- 网页提供微信接入引导界面。最终用户通过网页可自助接入微信。
- 加入多学习语言设置界面

多用户与用户认证：
- 支持多用户
- 支持用户管理、密码认证
- 用户之间容器隔离

简化安装：
- 容器化安装
- 完善安装文档
