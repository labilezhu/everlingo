# 🎉 EverLingo v0.1.0 发布！

经过几个月和 AI 一起打磨，**记了么（EverLingo）**终于迎来了第一个可用版本 —— **v0.1.0** 🚀

这是一个重要的里程碑。

从最初的想法，到今天能够真正拿来学习、记笔记、管理知识，EverLingo 已经具备了完整的基础能力。

## ✨ 本次更新亮点

### 📝 更聪明的 AI 笔记

让 AI 真正参与记笔记，而不是只负责聊天。

* ✍️ **Vibe Noting（氛围记笔记）**
  小记 Agent 能感知当前笔记编辑器的上下文。选中一句话，即可让它：

  * 进一步解释内容
  * 补充更多知识
  * 帮你续写或完善笔记

* 🔗 **支持笔记双向关联**

  * 笔记之间可直接互相链接
  * AI 回复中的笔记可直接点击跳转，形成知识网络

---

### 📱 更好的使用体验

EverLingo 不再只是桌面网页应用。

* 📱 全面优化移动端网页体验
* 🏠 支持安装为 **PWA（网页应用）**，可添加到手机主屏，一键启动
* 💬 新增微信接入引导页面，用户可自助完成微信绑定
* 🌍 新增多学习语言设置，一个账号支持学习多种语言

---

### 👥 多用户正式支持

EverLingo 现在已经具备多人部署能力。

* 👤 多用户管理
* 🔐 用户密码认证
* 🐳 用户级容器隔离，数据和运行环境互不影响

未来家庭版、小团队部署都已经具备基础能力。

---

### ⚙️ 更简单的部署

部署门槛进一步降低。

* 📦 Docker 容器化安装
* 📖 完善安装文档
* 🚀 几分钟即可完成部署

---
