# Release Notes 编写说明

在实施过程中，就同步记录下 Rlease Notes。

上一个版本： 见 [VERSION_HISTORY.yaml](/VERSION_HISTORY.yaml)
当前在开发的版本： 见 [VERSION_HISTORY.yaml](/VERSION_HISTORY.yaml)

文件的位置和结构，以下以 v0.1.1 为例 ：

位置： docs/release-notes/v0.1.1/v0.1.1-rel-notes.md

格式：
```markdown
# 🎉 EverLingo v0.1.1 release notes

## 新功能
- 每个 item 在 三句话内说明

## 功能增强
- 每个 item 在 三句话内说明

## 内部调整
- 每个 item 在 三句话内说明

## Breaking change

## Bugs fixing
- 每个 item 在 三句话内说明

```
