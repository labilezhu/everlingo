# 🎉 EverLingo v0.1.2 release notes

## New Features

- Added Memory Vault version control and remote backup: `$workspace/memory` is now a git repository, with an in-process committer that auto-commits at a configurable interval and pushes to the user's own git remote (`ssh` / `https_pat` / `https_none`), so accidental deletions are traceable and vaults are recoverable on another machine.
- Added CLI commands `everlingo mem snapshot / push / pull / restore / log / vstatus` that delegate to the running indexer over its HTTP endpoints (`/version/*`), enabling manual commits, force-with-lease push, remote restore, and history browsing.

## Enhancements

- `reset_vault` now snapshots the current vault changes into git history before overwriting template specs, so user edits are never silently lost.
- `user_doc_set` no longer writes a `USER.md.bak` backup: history is now maintained by the Memory Vault git repo instead.

## Internal Changes

- Added `src/everlingo/mem/vault/version/` package: `git.py` (subprocess git CLI wrapper: init/status/commit/push/fetch/rebase/log/branch/reset, always passing `-c safe.directory` for uid-mismatched mounted workspaces), `committer.py` (timer-based auto-commit with debounce + push interval, initial-commit fallback and atexit/stop final commit), `ssh_key.py` (temporary private-key lifecycle + `GIT_SSH_COMMAND` injection with `StrictHostKeyChecking=accept-new`), and `restore.py` (commit → fetch → rebase, conflicts preserved into a `backup/restore-<ts>` branch without touching the working tree).
- Added `git_backup` configuration section to `everlingo.yaml` (`enabled` / `remote_url` / `branch` / `auth` / `commit_interval` / `push_interval`) with `setting.load_git_backup()` / `save_git_backup()`.
- Indexer `AppState` now owns a `Committer` that is started/stopped with the process lifespan; `git init` is lazy on first startup and performs an initial commit capturing existing vault content.
- Indexer HTTP adds `/version/status`, `/version/commit`, `/version/push`, `/version/pull`, `/version/log`, and `/version/restore` endpoints; the SearchClient gains matching methods.
