# 🎉 EverLingo v0.1.2 release notes

## 新功能

- 新增 Memory Vault 版本控制与远端备份：`$workspace/memory` 整体作为 git repo，由 indexer 进程内 committer 按可配置间隔自动 commit、并按间隔 push 到用户自己的 git 远端（`ssh` / `https_pat` / `https_none` 三种凭证），误删可回溯、异机可恢复。
- 新增 CLI 命令 `everlingo mem snapshot / push / pull / restore / log / vstatus`，经 HTTP 委托运行中的 indexer（`/version/*` 端点），支持手动 commit、force-with-lease push、远端恢复与历史查看。

## 功能增强

- `reset_vault` 覆盖模板 spec 前先把当前改动快照进 git 历史，用户对 spec 的修改不再被静默丢失。
- `user_doc_set` 不再写 `USER.md.bak`：历史改由 Memory Vault 的 git 版本控制统一回溯。

## 内部调整

- 新增 `src/everlingo/mem/vault/version/` 包：`git.py`（subprocess 封装 git CLI：init/status/commit/push/fetch/rebase/log/branch/reset，统一带 `-c safe.directory` 规避挂载 workspace 的 UID 不匹配）、`committer.py`（定时器 commit 去抖 + push 间隔，initial commit 兜底与 atexit/stop final commit）、`ssh_key.py`（临时私钥生命周期 + `GIT_SSH_COMMAND` 注入，含 `StrictHostKeyChecking=accept-new`）、`restore.py`（commit → fetch → rebase，冲突归档到 `backup/restore-<ts>` 分支且不覆盖工作区）。
- `everlingo.yaml` 新增 `git_backup` 配置段（`enabled` / `remote_url` / `branch` / `auth` / `commit_interval` / `push_interval`），提供 `setting.load_git_backup()` / `save_git_backup()`。
- indexer `AppState` 持有 `Committer`，随进程 lifespan 启停；首次启动懒加载 `git init` 并做 initial commit 捕获存量 vault 内容。
- indexer HTTP 新增 `/version/status`、`/version/commit`、`/version/push`、`/version/pull`、`/version/log`、`/version/restore` 端点，SearchClient 补充对应方法。
- indexer 启动时强制将本地 git 分支重命名为配置的 `branch`（`git branch -M`）：异机初始化或手工拿到的 Memory Vault repo，无论原分支名是什么，push / fetch-rebase / status 的判断都保持一致。

## 新功能（二期 · P3）

- 新增备份配置页 `/console/me/backup`（Me 页常驻入口）：展示仓库状态（初始化 / dirty / 上次提交 / ahead-behind / 远端 / 分支）、配置表单（开关 / 远端 URL / 分支 / SSH 私钥）、操作区（测试连接 / 立即快照 / 立即推送 / 拉取恢复 / Hard Reset 二次确认）与提交历史列表。
- 新增 gateway REST API `/api/backup/*`（status/config/snapshot/push/pull/test/reset-hard/log/restore），复用 indexer 的 `/version/*` 端点经 UDS 委托，配置读写 `everlingo.yaml` 的 `git_backup` 段。

## 功能增强（二期 · P3）

- 配置保存即热生效：新增 `/version/apply-config` 端点 + `Committer.apply_config()/reload_config()`，保存配置后自动启停 committer 定时线程、重配 SSH 上下文，无需重启 indexer 进程。
- 新增「测试连接」：`git ls-remote` 只读探测配置的远端（复用 `git_backup` 凭证），接入 `/version/test` 端点。
- 新增「Hard Reset 到远端」强操作：`/version/reset-hard` 直接 `git reset --hard origin/<branch>`，UI 带二次确认（`git_backup` 配置后由用户显式触发，冲突恢复场景的兜底分支逻辑沿用 `restore.py`）。
