# 🎉 EverLingo v0.1.1 release notes

## 新功能

- 目标学习语言设置页添加「重新初始化」按钮：用户可一键重置知识库规范（spec/）到模板初始状态，覆盖用户自定义修改。

## 功能增强

- Me 页底部展示当前 EverLingo 版本号，便于用户识别运行版本。
- Web Chatbot 会话状态持久化：chatbot 与笔记编辑器之间跳转（整页刷新）后，同一浏览器 Tab 内保持同一会话与消息历史，AI 上下文连续，不再清空。
- 会话按 Tab 隔离：新开 Tab 得到独立新会话，用户可在浏览器中同时保留多个互不干扰的对话。

## 内部调整

- MCP 新增 reset_vault 工具（仅重置 spec/*.md，不碰用户笔记数据），后端新增 POST /api/target-language/reset-vault 端点。
- vault MCP server 工具计数统一修正为 18 个（文档/注释/指令文本同步更新，顺带补全此前 list_tags 漏列的问题）。
- 前端新增统一 fetch 包装（apiFetch / apiFetchJson）：所有 API 请求收到 401 时自动跳转登录页，并统一结构化错误处理；新增 React ErrorBoundary 兜底渲染异常，避免白屏。
- Web 页面 HTML 外壳（/、/login、/editor、/console/*、/self-service*）加 `Cache-Control: no-store`，静态 hash 资源加 immutable 长缓存，manifest 加 no-cache，避免 iOS PWA/浏览器缓存旧前端。

## Bugs fixing

- 修复 iOS 主屏 PWA 使用一段时间后打开白屏的问题：认证过期/服务端重启后，应用从后台恢复时不再静默失败，而是复检认证态并兜底跳转登录页或提示重新加载。
- 修复服务端重启后聊天会话失效的死循环：SSE 检测到会话过期时自动清除本地持久化的旧会话并重建新会话，无需手动刷新页面。
- 笔记编辑器语言选择下拉框现在默认选中 `everlingo.yaml` 配置的默认目标学习语言（`user_profile.language.target_language`），而非仅是 vault 列表第一项；`GET /api/vault/langs` 响应当中新增 `default` 字段，前端据此预选。
