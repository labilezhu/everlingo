# Yes、 No 的回答

别人问：

Didn't you go yesterday?

如果你去了，应该回答：

Yes, I did.

很多中国人会错误回答：

No.

因为他们是在回答"没有（不是没去）"，而英语回答的是事实。

这是典型的 pragmatics 问题
