# Answering Yes / No

When someone asks:

Didn't you go yesterday?

If you DID go, you should answer:

Yes, I did.

Many Chinese speakers wrongly answer:

No.

Because they are literally replying "No (I didn't not go)", whereas English answers the fact.

```

This is a typical pragmatics problem.
